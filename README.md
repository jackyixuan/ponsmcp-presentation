## Overview

This is the frontend presentation layer for PonsMCP. It showcases PonsMCP's autonomous payment infrastructure for AI agents using Stripe's Machine Payments Protocol (MPP), settled transparently on Robinhood Chain with USDG.

**Live:** [pons-mcp.pages.dev](https://pons-mcp.pages.dev)

---

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 7
- **Styling:** Tailwind CSS v3
- **UI Components:** shadcn/ui
- **Font:** Plus Jakarta Sans, DM Mono

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/jackyixuan/pons-mcp.git
cd pons-mcp
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```
